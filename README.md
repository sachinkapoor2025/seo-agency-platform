# SEO Agency Platform

Next.js foundation for an international SEO agency website and a later admin platform. This repository currently contains the application shell only.

## Prerequisites

- Node.js 20.9 or later
- npm

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

The application is served at [http://localhost:3000](http://localhost:3000).

## Linting

```bash
npm run lint
```

## Build

```bash
npm run build
npm start
```

Environment files are not included. Files matching `.env*` are ignored by Git.
